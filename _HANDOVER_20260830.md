## 3. Mobile Spacing Pattern (canonical)

Every hero across all 8 pages now follows this exact pattern:

```
<section className="relative min-h-screen flex items-center justify-center overflow-hidden">
  {/* Background image */}
  <div className="absolute inset-0">
    <Image ... />
  </div>
  
  {/* Overlay */}
  <div className="absolute inset-0 bg-black/65" />
  
  {/* Text container — absolute centered */}
  <div className="absolute inset-0 z-10 flex items-center justify-center">
    <div className="text-center px-4">
      
      {/* Tagline */}
      <p className="text-[6px] sm:text-[8px] md:text-[10px] tracking-[0.3em] uppercase text-white/80 mb-4">
        ...
      </p>
      
      {/* H1 */}
      <h1 className="text-[2rem] sm:text-4xl md:text-5xl lg:text-6xl font-bold text-white mb-4">
        ...
      </h1>
      
      {/* Paragraph */}
      <p className="text-white/80 text-sm md:text-base max-w-sm mx-auto mb-6">
        ...
      </p>
      
      {/* Buttons */}
      <div className="flex flex-row flex-nowrap justify-center gap-4">
        <button className="px-5 py-3 ...">...</button>
        <button className="px-5 py-3 ...">...</button>
      </div>
      
    </div>
  </div>
</section>
```

### Spacing Rules (non-negotiable)
| Element pair | Class | Rationale |
|-------------|-------|-----------|
| Tagline → H1 | `mb-4` (16px) | Consistent breathing room |
| H1 → Paragraph | `mb-4` (16px) | Matches above |
| Paragraph → Buttons | `mb-6` (24px) | Extra space before CTA |
| Paragraph max-width | `max-w-sm` (384px) | Never wider than H1 |
| H1 mobile size | `text-[2rem]` (32px) | 2-word lines wrap cleanly at 375px |
| Tagline mobile size | `text-[6px]` | Subtle, not competing with H1 |
| Button padding | `px-5 py-3` | Compact enough for side-by-side on 375px |
| Button layout | `flex-row flex-nowrap` | Side by side, never stacked |
| Overlay color | `bg-black/65` | Uniform across all pages |
| Hero height | `min-h-screen` | Full viewport on all devices |

## 4. Design Decisions & Rationale

**Why `absolute inset-0 z-10 flex items-center justify-center` for text container?**
This positions text dead-center over the hero image regardless of viewport height. The `absolute` positioning means text does not affect the hero's layout flow, and `z-10` ensures it sits above the overlay.

**Why `max-w-sm` instead of `max-w-md`?**
`max-w-md` (448px) caused paragraphs to extend beyond the H1 width on mobile. `max-w-sm` (384px) keeps paragraphs visually contained within the H1 bounding box at 375px viewport.

**Why `min-h-screen` instead of `min-h-[72vh]`?**
72vh left a gap at the bottom of the viewport on shorter screens. `min-h-screen` guarantees full-bleed hero on all devices and matches the designs page pattern that was already working.

**Why `bg-black/65` everywhere?**
The web-design page had `bg-black/30` which was too light for white text legibility. 65% opacity provides consistent contrast across all hero images regardless of underlying photo brightness.

**Why reduce the logo 30%?**
The original logo size competed with hero text on mobile. The reduced size (15px mobile, 18px sm, 22px lg) keeps branding visible without dominating the navbar.

**Why `semislow` (28s) for marquees?**
Original speeds felt rushed on wider marquees. 28s gives a从容阅读 pace without being sluggish.

## 6. Replication Notes

To apply this pattern to a new page:

1. Hero section: `className="relative min-h-screen flex items-center justify-center overflow-hidden"`
2. Image wrapper: `className="absolute inset-0"`
3. Overlay: `className="absolute inset-0 bg-black/65"`
4. Text container: `className="absolute inset-0 z-10 flex items-center justify-center"`
5. Inner div: `className="text-center px-4"`
6. Tagline: `mb-4`, `text-[6px] sm:text-[8px] md:text-[10px]`
7. H1: `mb-4`, `text-[2rem] sm:text-4xl md:text-5xl lg:text-6xl`
8. Paragraph: `mb-6`, `max-w-sm mx-auto`
9. Buttons: `flex flex-row flex-nowrap justify-center gap-4`, `px-5 py-3`

Do not deviate from these values without testing at 375px viewport width.
