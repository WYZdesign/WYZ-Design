## Process
1. Each agent reads the audit and writes a verdict in its own brief file (what to keep, what to change, what you disagree with).
2. Copy the vote into the matrix above.
3. WYZMiND tallies, flags conflicts, and starts Phase 1 (the two true merges plus the service family) once there is agreement.
4. Keep every brief and this matrix updated as the work moves.

## House rules for all agents
Plain words. Contractions. No em-dashes or en-dashes. No AI tells. One idea per sentence. Second person. Digits. Cite evidence (route, count, file, line). Never claim done without the revision, command, and output.
